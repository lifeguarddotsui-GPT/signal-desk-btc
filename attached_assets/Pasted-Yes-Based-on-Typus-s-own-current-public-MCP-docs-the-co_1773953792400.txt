	1.	Fetch open positions, not pending orders. Use the wallet address to call get_positions and read the live positionId, marketIndex, size, side, and close fee fields. 	3.	Submit a reduce-only market-close order with create_order. Typus’s documented example closes a position by creating an opposite-side order with:
	•	same tradingToken
	•	same size as the open position
	•	collateralAmount="0"
	•	reduceOnly=true
	•	linkedPositionId="<positionId>"
	•	triggerPrice="1" for market-close behavior.  ￼
	4.	Flip the side relative to the open position. For a long, the close order uses isLong=false; for a short, the close order uses isLong=true. Typus’s example shows a long being closed with isLong=false.  ￼
	5.	Do not call cancel_order unless you are canceling a pending order. cancel_order is only for a pending trading order and requires orderId plus marketIndex; it is not the documented close flow for a live position.  ￼
