Executive Summary

Build a minimal crypto-only 15-minute prediction market edge scanner. The app should watch only BTC, ETH, and SOL 15-minute markets, compare the market’s implied odds against a verifiable oracle-based price model, and show the user where the best opportunity is.

No sports. No teams. No betting language. No clutter.

The app should answer one question:

“Where is the strongest 15-minute crypto edge right now?”

4. Edge Calculation Logic

The app should estimate whether Over or Under has positive expected value.

Inputs:

* Current oracle price
* Target price
* Time remaining
* Recent volatility
* Price distance from target
* Market payout odds
* Oracle confidence range

Basic model:

distance = current_price - target_price
time_remaining = seconds until market close
volatility = recent short-term realized volatility
fair_probability = probability price finishes above target
market_probability = 1 / payout_multiplier
edge = fair_probability - market_probability

For Under:

under_fair_probability = 1 - over_fair_probability
under_market_probability = 1 / under_payout
under_edge = under_fair_probability - under_market_probability

Then score:

Edge Score = edge percentage × confidence multiplier × time multiplier

Suggested ratings:

* 0–20: No Edge
* 21–40: Weak Edge
* 41–60: Moderate Edge
* 61–80: Strong Edge
* 81–100: Excellent Edge

The app should never guarantee profit.

Use language like:

“Best estimated edge”
not
“Guaranteed win.”
