🛠 How To Fix It (Correct Architecture)

This is the correct pattern for perps on SUI:

⸻

✅ Step 1 — Fetch Fresh Oracle

const oraclePrice = await typus.getOraclePrice({
  market: "SUI-PERP"
});

Do this immediately before building tx.

⸻

✅ Step 2 — Calculate Execution Price With Buffer

Add buffer to protect from mismatch:

const slippageBps = 150; // 1.5%

const executionPrice = isLong
  ? oraclePrice * (1 + slippageBps / 10000)
  : oraclePrice * (1 - slippageBps / 10000);

Do NOT use float math.
Use BigInt scaling:

const BPS = 10000n;
const buffer = 150n;

const executionPrice = isLong
  ? oraclePrice * (BPS + buffer) / BPS
  : oraclePrice * (BPS - buffer) / BPS;


⸻

✅ Step 3 — Pass Oracle Version + Price Correctly

Typus usually requires:
	•	oracle price
	•	oracle timestamp
	•	oracle update ID

Make sure you are passing:

oracle.price
oracle.confidence
oracle.timestamp

If you only pass price → reject.

⸻

✅ Step 4 — Increase Allowed Slippage

At 36x leverage, use:

150–300 bps

Not 50 bps.

⸻

✅ Step 5 — Stop Instant Retry Loop

Add guard:

if (error.includes("oracle_mismatched")) {
   await sleep(1500);
   return;
}

Otherwise you spam failed transactions.

⸻

🧪 Quick Debug Checklist

console.log("Oracle price:", oraclePrice.toString());
console.log("Execution price:", executionPrice.toString());
console.log("Slippage:", slippageBps);

If executionPrice < oracle price for LONG → automatic reject.
