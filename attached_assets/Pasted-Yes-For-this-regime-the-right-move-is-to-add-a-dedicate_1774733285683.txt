Aggressive Chop Scalper — Strategy Spec

Objective

Generate more capital during low-volatility, sideways, choppy conditions by scalping repeated mean-reversion moves and short-lived micro-impulses rather than waiting for trend breakouts.

Core idea

When the market is not trending, the agent should stop acting like a breakout trader and start acting like a range scalper.

The agent should:
	•	long near local support
	•	short near local resistance
	•	take smaller profits faster
	•	cut losers faster
	•	trade more often
	•	avoid getting trapped in real breakouts

⸻

Regime Definition

Enter CHOP_SCALP mode when all or most of the following are true

Use 1h as regime frame, 5m and 15m as execution frames.

CHOP_SCALP mode if:
- RSI(14, 1h) between 40 and 60
- MACD histogram (1h) weak / near flat
- EMA7 and EMA30 distance small
- 1h realized volatility low relative to last 7 days
- price repeatedly rejects local highs/lows
- no strong directional expansion candle on 1h

Strategy Structure

Long setup

Short setup

B. Micro-Momentum Confirmation

Do not blindly catch knives. Require tiny reversal evidence.

Long confirmation

Any 1 of:
	•	5m close back above EMA7
	•	bullish rejection wick at support
	•	MACD histogram on 5m improving

Short confirmation

Any 1 of:

C. Fake Breakout Fade

If price briefly breaks the range but cannot hold it, fade the move.

Long fake-breakdown
	•	price wicks below support
	•	closes back inside range
	•	volume not expanding meaningfully
	•	enter long

Short fake-breakout
	•	price wicks above resistance
	•	closes back inside range
	•	volume not expanding meaningfully
	•	enter short

This should be a high-priority chop setup.

2. Add chop regime detector

function detectMarketRegime(data1h): MarketRegime {
  const rsi = data1h.rsi14;
  const macdHist = Math.abs(data1h.macdHistogram);
  const emaSpreadPct = Math.abs(data1h.ema7 - data1h.ema30) / data1h.price * 100;
  const lowVol = data1h.realizedVol < data1h.avg7dVol * 0.75;
  const breakout = Math.abs(data1h.lastCandlePctMove) > 0.9;

  if (!breakout && rsi >= 40 && rsi <= 60 && emaSpreadPct <= 0.35 && lowVol && macdHist < data1h.macdFlatThreshold) {
    return MarketRegime.CHOP_SCALP;
  }

  if (breakout) return MarketRegime.BREAKOUT;
  return MarketRegime.TREND;
}

3. Build rolling range

Use 15m and 5m candles.

function buildRange(data15m) {
  const highs = data15m.slice(-32).map(c => c.high);
  const lows = data15m.slice(-32).map(c => c.low);

  const rangeHigh = Math.max(...highs);
  const rangeLow = Math.min(...lows);
  const rangeSize = rangeHigh - rangeLow;
  const rangeMid = (rangeHigh + rangeLow) / 2;

  return {
    rangeHigh,
    rangeLow,
    rangeMid,
    supportThreshold: rangeLow + rangeSize * 0.20,
    resistanceThreshold: rangeHigh - rangeSize * 0.20,
    neutralLow: rangeLow + rangeSize * 0.30,
    neutralHigh: rangeHigh - rangeSize * 0.30,
    rangeSize,
  };
}

function scoreChopScalpSetup(ctx) {

function detectFakeBreakout(price, candle, range, volumeState) {
  const brokeAbove = candle.high > range.rangeHigh;
  const brokeBelow = candle.low < range.rangeLow;
  const closedInside = candle.close < range.rangeHigh && candle.close > range.rangeLow;
  const weakVolume = volumeState !== "strong";

  return (brokeAbove || brokeBelow) && closedInside && weakVolume;
}
