Add this table immediately

  id uuid primary key default gen_random_uuid(),
  direction text not null check (direction in ('in', 'out')),
  source_type text not null, -- 'position_close', 'manual_adjustment', 'claim', 'reversal', 'migration'

Then backfill historical inflows

For every historical reward entry:

1) find the position close that created it
2) find the tx digest that funded the reward wallet
3) match amount exactly
4) match owner wallet exactly
5) match agent exactly
6) mark whether the reward was later claimed

Diagnostic query

select
  source_agent_id,
  owner_wallet_address,
  source_position_id,
  tx_digest,
  amount,
  created_at
from reward_wallet_ledger
where direction = 'in'
order by created_at desc;

Reconciliation query

select
  coalesce(sum(case when direction = 'in' then amount else 0 end), 0) -
  coalesce(sum(case when direction = 'out' then amount else 0 end), 0) as expected_reward_wallet_balance
from reward_wallet_ledger;

If that does not equal the on-chain reward wallet balance, you have a leak or accounting bug.

Current model problem

The current reward model appears to do something like this:

-> pnl computed

This causes 4 major problems.

You said the agents should maximize their own portfolio growth and free SUI growth.

That means the default policy should be:

profits stay with the agent unless explicitly withdrawn by the owner

profits are siphoned into a separate reward wallet first

PART 7 — How free SUI should work after redesign

Canonical definition

freeSui =
agent_wallet_on_chain_balance
- reserved_gas_buffer
- locked_open_position_collateral
- pending_withdrawals
+ confirmed_returned_close_proceeds_not_yet_swept

Critical rule

It must reconcile to:

actual wallet SUI
+ internal reserved accounting
- open commitments

Update logic on close

async function settleClosedPosition(positionId: string) {
  const position = await getPosition(positionId);
  const closeResult = await fetchOnChainCloseSettlement(position.closeTxDigest);

  const returnedCollateral = closeResult.returnedCollateral;
  const realizedPnl = closeResult.realizedPnl;
  const protocolFee = calculateProtocolFee(realizedPnl);
  const ownerPayout = calculateOwnerPayout(realizedPnl, position.agentId); // likely 0
  const retainedProfit = Math.max(realizedPnl - protocolFee - ownerPayout, 0);

  await db.transaction(async (tx) => {
    await tx.update(positions)
      .set({
        status: "closed",
        returnedCollateral,
        realizedPnl,
        closeTxDigest: closeResult.txDigest,
        settledAt: new Date()
      })
      .where(eq(positions.id, positionId));

    await tx.insert(profitAllocations).values({
      agentId: position.agentId,
      positionId,
      ownerWalletAddress: position.ownerWalletAddress,
      grossPnl: realizedPnl,
      returnedCollateral,
      retainedInAgent: returnedCollateral + retainedProfit,
      ownerPayoutAmount: ownerPayout,
      protocolFeeAmount: protocolFee,
      settlementTxDigest: closeResult.txDigest
    });

    await tx.update(agents)
      .set({
        freeSui: sql`${agents.freeSui} + ${returnedCollateral + retainedProfit}`,
        totalRealizedPnl: sql`${agents.totalRealizedPnl} + ${realizedPnl}`
      })
      .where(eq(agents.id, position.agentId));
  });
}
