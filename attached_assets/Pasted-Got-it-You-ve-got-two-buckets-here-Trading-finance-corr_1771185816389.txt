A) Trading + Funds

1) Enforce minimum per-position size = 10 SUI (Typus requirement)

Right now you’re trying to open tiny positions → rejects / wastes gas.

✅ Add a hard preflight check (UI + backend)
	•	If user collateral < 10 SUI → disable Start + show message
	•	If order size < 10 SUI equivalent → don’t submit tx

Example (TypeScript):

const MIN_SUI_PER_POSITION = 10n; // 10 SUI
const SUI_DECIMALS = 1_000_000_000n;

export function suiToMist(sui: number): bigint {
  return BigInt(Math.floor(sui * 1e9));
}

export function assertMinPositionSui(positionSizeMist: bigint) {
  if (positionSizeMist < MIN_SUI_PER_POSITION * SUI_DECIMALS) {
    throw new Error(`MIN_POSITION_10_SUI: positionSizeMist=${positionSizeMist}`);
  }
}

Where to apply:
	•	right before building the Typus transaction (server/agent)
	•	and on the client before user can start

If your “Max Notional” is in USD, you still enforce collateral input in SUI:
	•	collateral_sui >= 10 OR if Typus minimum is “margin per position”, enforce that exactly.

2) “Withdrawal errors / lost SUI” — what’s actually happening + fix

Two things can be true at once:

What’s likely happening
	1.	Failed txs still burn gas → you didn’t “lose collateral”, you paid gas repeatedly due to retries.
	2.	Your “withdraw” flow may be trying to withdraw from an object that’s locked, empty, or not the right vault/cap.

✅ Fix requirements

(a) Add a hard circuit breaker that stops BEFORE gas drain
	•	After 1 oracle_mismatched OR version_check, pause 60s, don’t keep firing.
	•	Disable retries unless oracle is re-fetched and tx rebuilt (no replays).

(b) Add “Withdrawal: simulate then execute”
On Sui you can do a dry-run / dev-inspect before sending a tx to avoid guaranteed failures.

Pattern:

// Pseudocode – adapt to your Sui client
const dry = await suiClient.devInspectTransactionBlock({
  sender: walletAddress,
  transactionBlock: tx,
});

if (dry.effects.status.status !== "success") {
  throw new Error("WITHDRAW_SIM_FAILED: " + JSON.stringify(dry.effects.status));
}

await signer.signAndExecuteTransactionBlock({ transactionBlock: tx });

(c) Fix withdrawal target
If your agent uses a dedicated agent wallet, “withdraw” must:
	•	close/cancel open orders
	•	close position (if any)
	•	withdraw remaining margin/collateral from Typus vault to agent wallet
	•	then transfer SUI from agent wallet → user wallet

Also: show a clear breakdown:
	•	Recoverable balance vs Gas spent vs Open margin locked

(d) Add a “Recover Funds” button
One-click:
	1.	cancel all orders
	2.	close all positions (market close)
	3.	withdraw all
	4.	transfer out

Even if step 2 fails, do step 1 and step 3.

4) Agent tab UI cut off on mobile

This is almost always:
	•	fixed-height containers
	•	missing overflow-y-auto
	•	bottom nav overlapping content
	•	not using safe-area insets on iOS

✅ Requirements
	•	main content must scroll independently
	•	add bottom padding equal to navbar height
	•	use iOS safe area padding

React/Tailwind pattern:

export function Page({ children }: { children: React.ReactNode }) {
  return (
    <div className="min-h-dvh w-full bg-neutral-950 text-white">
      {/* main scroll area */}
      <main className="px-3 pt-3 pb-24 overflow-y-auto">
        {children}
      </main>

      {/* bottom nav fixed */}
      <nav className="fixed bottom-0 left-0 right-0 h-20 bg-neutral-900/95 backdrop-blur border-t border-white/10">
        {/* nav buttons */}
      </nav>
    </div>
  );
}

If you’re using iOS notch/safe area, add:

.pb-safe { padding-bottom: env(safe-area-inset-bottom); }
.pt-safe { padding-top: env(safe-area-inset-top); }

and apply to header/nav.
