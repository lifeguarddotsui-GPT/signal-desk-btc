✅ 2. Use On-Chain Pyth Oracle Data

Typus Perps uses Pyth price feeds on SUI to price markets*, so your agent must:

🔹 Fetch price from the Pyth oracle object

Use Sui RPC to query the Pyth price feed object directly.

Sample pseudocode

import { SuiClient } from '@mysten/sui.js/client';

const client = new SuiClient({ url: RPC_URL });

// Fetch on-chain Pyth price object
async function getOnChainPrice(objectId: string) {
  const obj = await client.getObject({
    id: objectId,
    options: { showContent: true },
  });

  // parse actual price from object fields
  const price = Number(obj.data.content.fields.price) / 10 ** Number(obj.data.content.fields.exponent * -1);
  return price;
}

✅ This will retrieve price data on-chain instead of via HTTP.
