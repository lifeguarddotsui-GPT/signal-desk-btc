Concrete comparison

What the successful manual close should look like

For a real open position, the close path should be:
	1.	Read the live position from get_positions
	2.	Take its exact positionId
	3.	Submit a new opposite-side create_order
	4.	Set:
	•	reduceOnly = true
	•	linkedPositionId = <live positionId>
	•	collateralAmount = "0"
	•	full remaining size
	•	market-close style trigger as supported by Typus docs.  ￼

What the failing agent flow appears to be

Your labels strongly suggest this sequence:
	1.	Agent cancels a linked pending order
	2.	Agent submits some other contract call
	3.	Wallet pays gas
	4.	Position does not actually settle back to SUI

That usually means one of these is happening:
	•	the agent is operating on the order layer, not the position layer
	•	the second call is missing the correct live positionId
	•	the second call is not a true reduce-only close
	•	the agent is submitting a close with the wrong side / wrong size / stale object state

The most likely root bug

The most likely bug is:

Your agent is treating “cancel linked order” as part of the close itself, instead of treating it as optional cleanup around the real close call.

That matters because:
	•	canceling TP/SL or linked orders does not close the live position
	•	only the reduce-only close order linked to the live position closes the position.  ￼

The concrete solution

Rule 1

Never use cancel_order as the primary close action.

Only use it to remove pending TP/SL / limit orders that might interfere.

Rule 2

The actual close action must always be:
	•	source position from get_positions
	•	extract exact live positionId
	•	submit one close order with:
	•	opposite side
	•	reduceOnly: true
	•	linkedPositionId: position.positionId
	•	collateralAmount: "0"
	•	exact remaining size.  ￼

Rule 3

After the close transaction confirms, immediately re-query get_positions.

Success condition is not “tx succeeded.”
Success condition is:
	•	position disappears from get_positions, or
	•	remaining size becomes zero

If neither happens, mark it as close failed.

    isLong: !position.isLong,       // opposite side
    collateralAmount: "0",

    linkedPositionId: position.positionId,
    dryRun: false,
  };
