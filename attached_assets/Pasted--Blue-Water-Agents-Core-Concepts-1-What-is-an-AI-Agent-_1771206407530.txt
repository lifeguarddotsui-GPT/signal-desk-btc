🌊 Blue Water Agents — Core Concepts

⸻

1️⃣ What is an AI Agent?

An AI Agent is a software entity that:
	•	Perceives information (market data, wallet state, UI input)
	•	Decides based on rules, models, or algorithms
	•	Acts autonomously (executes trades, updates UI, sends transactions)
	•	Learns or adapts (optional layer)

In simple terms:

An AI Agent is a decision-making program that can take actions on your behalf.

There are different types of agents:

Type	Example
Rule-Based	“If RSI < 30 → go long”
Algorithmic	EMA crossover strategies
ML-Driven	Pattern recognition models
Multi-Agent	One agent analyzes, one executes

Blue Water Agents are multi-agent, off-chain AI trading agents that execute on-chain actions.

⸻

2️⃣ What is Automation?

Automation = software performing tasks without manual human input each time.

Example:

Manual:
You log into Typus → choose size → sign transaction → confirm.

Automated:
Agent monitors market → generates signal → builds transaction → sends to wallet → executes.

Automation reduces:
	•	Emotional trading
	•	Reaction lag
	•	Human error
	•	Execution friction

Your system uses off-chain automation + on-chain settlement.

⸻

🔹 Data

🔹 UI Interaction

⸻

4️⃣ What is an SDK?

SDK = Software Development Kit

An SDK is a toolbox developers use to build apps on a platform.

Example:
	•	Typus Finance SDK
	•	FlowX Finance SDK
	•	Square Web Payments SDK

An SDK includes:
	•	Libraries
	•	Prewritten functions
	•	Authentication helpers
	•	Transaction builders

Instead of building raw blockchain logic from scratch, you use the SDK to interact safely.

⸻

5️⃣ What is an API?

API = Application Programming Interface

An API is how software talks to other software.

Think of it like a contract:

“If I send this request, you send me this data.”

Example:
	•	Request: “Give me SUI price.”
	•	Response: “$1.82”

APIs can:
	•	Fetch price data
	•	Return account balances
	•	Submit transactions
	•	Pull order books

SDKs often wrap APIs.

⸻

6️⃣ What is an RPC?

RPC = Remote Procedure Call

In blockchain terms:

RPC = The gateway to the blockchain.

It allows your app to:
	•	Read chain data
	•	Send transactions
	•	Check balances
	•	Query smart contracts

For SUI:

RPC connects to a SUI full node.

Without RPC:
You cannot interact with the blockchain.

RPC handles:
	•	Gas estimation
	•	Transaction simulation
	•	State verification

If RPC fails → bundles fail → agent “can’t trade.”

This is directly relevant to your recent gas rejection errors.

7️⃣ What is a Smart Contract?

A smart contract is on-chain code that:
	•	Holds logic
	•	Enforces rules
	•	Executes deterministically

Perp exchanges use smart contracts to:
	•	Manage margin
	•	Track positions
	•	Calculate funding
	•	Enforce liquidation

Agents interact with these contracts.

⸻

8️⃣ What is Off-Chain vs On-Chain?

Off-Chain	On-Chain
AI logic	Settlement
Strategy computation	Position storage
Signal generation	Margin tracking
Market analysis	Liquidation logic

Blue Water Agents:
	•	Think off-chain
	•	Execute on-chain

This is critical for performance and ML capability.

⸻

9️⃣ What is a Transaction Bundle?

A bundle includes:
	•	Order instruction
	•	Margin deposit
	•	Gas payment
	•	Signature

If:
	•	Gas < required
	•	Oracle mismatch
	•	Minimum contract size not met

→ bundle rejected

This explains your previous Typus execution failures.

Let’s define the architecture clearly.

⚙️ Architecture Overview

Layer 1 — User Layer
	•	User funds agent wallet
	•	Grants session key or limited permissions
	•	Chooses risk profile

This agent:
	•	Reads SUI price

This agent:
	•	Validates:

	•	Sends to SUI RPC
	•	Confirms inclusion
	•	Updates dashboard

Interacts with:
	•	Typus Finance
	•	Astros
	•	FlowX Finance

Depending on geographic eligibility.

Layer 5 — Dashboard Layer

Displays:
	•	SUI price
	•	Wallet balance
	•	Agent status
	•	Open positions
	•	Profit / Loss
	•	Risk exposure

🔒 Security Model

Blue Water Agents should use:
	•	Session keys (preferred)
	•	Spending limits
	•	Time-based expiration
	•	RPC redundancy
	•	Gas buffer logic
	•	Simulation before execution
