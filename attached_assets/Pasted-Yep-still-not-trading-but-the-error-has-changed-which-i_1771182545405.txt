2) “Object already locked by a different transaction” — you’re submitting overlapping txs (race condition)

Your other screenshot shows:

“Transaction is rejected… object … already locked by a different transaction …”

That is a classic Sui concurrency issue: you have multiple in-flight transactions trying to use the same mutable object (position/account/collateral/oracle object).

This happens when your bot:
	•	retries too fast
	•	fires LONG and SHORT attempts close together
	•	runs multiple loops (signal loop + execution loop) at the same time
	•	doesn’t await finality before sending the next tx

Fix for “object locked”

You need a single-flight mutex/queue per wallet + market:
	•	only 1 order tx can be pending at a time
	•	if locked → backoff 1–3s and retry with a newly built tx

The exact fix package to give your Replit agent

A) Add a “tx mutex” so only one tx runs per agent wallet

class Mutex {
  private p: Promise<void> = Promise.resolve();
  lock<T>(fn: () => Promise<T>): Promise<T> {
    const run = this.p.then(fn, fn);
    this.p = run.then(() => undefined, () => undefined);
    return run;
  }
}
const txMutex = new Mutex();

Use it around all trade execution:

await txMutex.lock(async () => {
  await executeTradeOnce();
});

B) Retry policy by error type (important)

function isObjectLocked(msg: string) {
  return msg.includes("already locked") || msg.includes("Object") && msg.includes("locked");
}
function isVersionCheck(msg: string) {
  return msg.includes("version_check");
}

async function executeTradeOnce() {
  try {
    const oracle = await typus.oracle.getLatestForMarket("SUI-USD"); // MUST be fresh
    if (!oracle?.update) throw new Error("Missing oracle update");

    const tx = new Transaction();
    typus.tx.attachOracleUpdate(tx, oracle.update); // required

    // build order here...
    // typus.tx.placeLimitOrder(tx, {...})

    const res = await signer.signAndExecuteTransactionBlock({ transactionBlock: tx });
    return res;
  } catch (e: any) {
    const msg = String(e?.message ?? e);

    if (isVersionCheck(msg)) {
      // Oracle update stale/wrong: DO NOT reuse anything
      // wait briefly, refetch oracle next attempt
      await sleep(800);
      throw new Error("ORACLE_VERSION_CHECK_FAIL");
    }

    if (isObjectLocked(msg)) {
      // safe retry with backoff
      await sleep(1500);
      throw new Error("OBJECT_LOCKED_RETRY");
    }

    throw e;
  }
}
