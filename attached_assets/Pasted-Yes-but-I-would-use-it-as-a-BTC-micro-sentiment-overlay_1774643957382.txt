Yes — but I would use it as a BTC micro-sentiment overlay, not as a direct trading signal for SUI.

Polymarket’s market data is accessible through public APIs without auth, market prices are probabilities from a CLOB, and it has real-time data / price history endpoints you can query programmatically. Its 5-minute crypto markets are now a formal product category with fee handling documented in the changelog.  ￼

Core idea

Use the live BTC 5-minute Up/Down probability as a short-horizon risk gauge for the whole crypto tape, then let it influence SUI agents only when it agrees with your own market structure signals.

That means:
	•	If BTC 5-minute odds are leaning strongly up and strengthening, that is a tailwind for SUI longs.
	•	If BTC 5-minute odds are leaning strongly down and strengthening, that is a headwind for SUI longs and a tailwind for SUI shorts.
	•	If Polymarket is near 50/50 or rapidly flipping, treat it as noise and ignore it.

This is useful because Polymarket prices are literally crowd probabilities, and those probabilities update from live order-book activity. But it should stay secondary, because it is still a separate market with its own fees, spreads, and trader behavior.  ￼

Best way to use it

Do not do this:
	•	“Polymarket says BTC up 51%, therefore long SUI.”

Do this instead:
	•	“Polymarket BTC 5m probability is 58% up, rising from 53% over the last 2 minutes, while BTC spot is also pushing higher, and SUI’s own EMA/RSI/volume setup is bullish — allow longs with slightly more confidence.”

So the engine should answer 3 questions:
	1.	Direction — is Polymarket leaning up or down?
	2.	Acceleration — is that probability strengthening or weakening?
	3.	Agreement — does it agree with BTC spot momentum and SUI setup?

That is the version that can improve win rate.

Signal construction

Step 1: Build raw prediction score

rawPredictionScore =
  50 +
  (probUp - 0.50) * 100 +
  delta1m * 1.5 +
  delta3m * 1.0;

Interpretation:
	•	above 55 = bullish BTC micro-bias
	•	below 45 = bearish BTC micro-bias
	•	45–55 = noise

Step 2: Build agreement score

Compare Polymarket with:
	•	BTC 1m return
	•	BTC 5m return
	•	BTC tape direction
	•	SUI short-term trend state

agreementScore =
  30 * signMatch(probBias, btc1mTrend) +
  30 * signMatch(probBias, btc5mTrend) +
  20 * signMatch(probBias, btcTapeBias) +
  20 * signMatch(probBias, suiTrendBias);

Normalize to 0–100.

Step 3: Usability filter

Only use the overlay if:
	•	prediction market spread is not too wide
	•	probability has moved enough to matter
	•	market is live and fresh
	•	agreement score is acceptable

usable =
  spreadBps <= 120 &&
  Math.abs(probUp - 0.50) >= 0.03 &&
  agreementScore >= 55 &&
  dataAgeSec <= 20;

If not usable, return neutral.

Do not let this dominate your system.

Recommended weighting:

	•	BTC prediction overlay: 15–20% max

adjustedScore =

Allow stronger long bias only if:

overlay.usable &&

Allow stronger short bias only if:

overlay.usable &&

Block marginal trades if:

overlay.bias opposes tradeDirection &&

This is where win rate can improve: the overlay should help reject weak trades that are fighting the broader BTC micro-tape.

Important guardrails

1. Never use Polymarket alone

A prediction market can be informative, but it is not your execution venue and not your underlying SUI market. Its probabilities come from supply/demand in its own order book, and displayed prices may reflect midpoint or last trade depending on spread conditions.  ￼

2. Treat 51/49 as basically useless

Your screenshot’s 51% up reading is not enough edge by itself. Near-coinflip probabilities should be ignored unless:
	•	they are moving sharply
	•	and spot/perp price confirms

3. Use trend in the probability, not just level

A move from 50% to 58% is more useful than sitting flat at 52%.

4. Require freshness

If the data is stale, ignore it. Polymarket documents real-time streaming and history access, so use timestamps aggressively.  ￼

5. Backtest before live use

Log whether this overlay actually improves:
	•	win rate
	•	expectancy
	•	average hold quality
	•	avoided bad trades

Yes — you can build this, and it could help.
