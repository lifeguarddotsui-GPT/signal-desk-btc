4. Deterministic PnL Calculation

PnL must never be taken from a UI value or API summary.

It must be recomputed from raw events.

Calculation

function calculateRealizedPnL(agent) {

    const tradePnL =
        sum(agent.closedPositions.map(p => p.pnl))

    const fundingPnL =
        sum(agent.fundingPayments)

    const keeperRewards =
        sum(agent.keeperRewards)

    const tradingFees =
        sum(agent.tradingFees)

    const liquidationFees =
        sum(agent.liquidationFees)

    return (
        tradePnL +
        fundingPnL +
        keeperRewards -
        tradingFees -
        liquidationFees
    )
}

5. Reconciliation Engine

Run reconciliation every settlement cycle.

reconciliation interval = 60 seconds

Implementation

function reconcileAgent(agent) {

    const calculatedPnL =
        calculateRealizedPnL(agent)

    const reportedPnL =
        agent.reportedPnL

    const diff =
        Math.abs(calculatedPnL - reportedPnL)

    if (diff > 0.05) {

        log("PNL_MISMATCH", {
            agent: agent.name,
            calculatedPnL,
            reportedPnL,
            difference: diff
        })

        flagAgent(agent.id)
    }
}

7. Agent Watchdog System

Every agent must have an activity watchdog.

Logic

if idle_time > 2 hours
    reduce signal threshold
    allow medium confidence signals

Implementation

function agentWatchdog(agent) {

    const idleTime =
        Date.now() - agent.lastTradeTime

    if (idleTime > 7200000) {

        agent.signalThreshold *= 0.8

        agent.allowMediumConfidence = true

        log("AGENT_IDLE_ADJUSTMENT", {
            agent: agent.name,
            newThreshold: agent.signalThreshold
        })
    }
}
